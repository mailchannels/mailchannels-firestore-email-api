# MailChannels Firestore Email API — development preview

Unreleased candidate for a Firestore outbox function kit using the MailChannels
Email API. Implementation and validation are under review in the candidate PR;
there is no npm release, supported production deployment or Firebase Hub listing.

Firebase Extensions Hub is closed to new publishers. This project explores an
alternative npm/function-kit distribution route, not a replacement Hub listing.

## Support

This project is supported by the MailChannels team on a best-effort basis. The best way to get support is to file an issue on GitHub: https://github.com/mailchannels/mailchannels-firestore-email-api/issues

If you are a MailChannels customer and have a problem with the operation of the MailChannels service, you can get support at https://support.mailchannels.com/
